# Credits

`w_mining` is an original `w_lib` implementation written for **Wraith Framework RedM** (GPL-3.0).

We acknowledge the RedM open-source community for documenting RDR2 mine coordinates, rock model names, pickaxe animations, and smelter locations:

- **VORP Core (`VORPCORE/vorp_mining`)** — RDR2 wild rock model list, town restriction hashes, and pickaxe animation reference.
- **RSG Framework (`Rexshack-RedM/rsg-rocks`, `rsg-mining`, `rsg-smelting`)** — Annesburg, Gaptooth Breach, Grizzlies, and Valentine smelter coordinates, female ped pickaxe animation fallback, and smelting recipe concepts.
- **Overextended (`ox_lib`)** — Underlying UI primitives extended in `w_lib`.
